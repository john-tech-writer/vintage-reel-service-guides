# Service notes - YouTube script

Basic service consists of:

1. Cleaning the parts and housing. This reel has already been cleaned, basically with paint thinner followed by detergent and warm water, then thorough drying.

2. Lubricating the *gears* with grease. Not too much.

3. Lubricate *all other parts* with oil. Not too much. 

Specific notes for this reel: 

  - Lubricate the shaft thoroughly but sparingly.

  - After re-assembly you can grease the gears via the grease disc and oil the crank via the hole in the crank nut.

See the generic service video for more details.
