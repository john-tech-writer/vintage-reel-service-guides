# README for purchase logs

*updated 8.22.26*

This folder contains the purchase logs for the Vintage Reel Service Guides project.

Currently there are two logs, one for vintage reels and one for vintage rods.

These logs include relevant information about the purchase history for each item. These files are private records and are not included in the public repository.

## What lives here - key files

vintage reel purchase log.docx

vintage-rod-purchase-log.md

Related: more details about each rod are in the workspace in `rods/`

## Working approach

The files here are updated whenever a new item is purchased as the first step in the workflow. Currently one file is in MS Word format and the other in Markdown, with the Word doc destined to be converted to Markdown. Markdown (md) files are authored and edited in Notepad ++. This folder is included in backups to Dropbox.

## Maintenance

This README will be updated when major files are added, renamed, moved, or removed and / or if this folder’s purpose changes.
